# Erdős problem 20: source collections

The latest report is **A1K Agentic SuperMath (2026), *An upper bound for four-uniform three-sunflower-free families***: [Zenodo record](https://zenodo.org/records/23647893) · DOI: [10.5281/zenodo.23647893](https://doi.org/10.5281/zenodo.23647893). Its ordinary computer-assisted result is **54 ≤ M(4, 3) ≤ 67** for finite simple four-uniform three-sunflower-free families, with an empty core allowed. The full upper-67 proof is not an end-to-end Lean theorem; the general Erdős–Rado sunflower conjecture remains outside this result.
